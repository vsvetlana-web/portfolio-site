# Артём Лесовой — сайт-портфолио

Одностраничный сайт-визитка видеомонтажёра. Тёмная тема, адаптивная вёрстка,
без сборки и зависимостей — только один HTML-файл со встроёнными стилями и
скриптом.

## Стек

- Чистый HTML + CSS (всё внутри `index.html`, тег `<style>`)
- Немного ванильного JavaScript (`<script>` в конце файла)
- Шрифты Google Fonts: Onest, Playfair Display, Caveat

## Структура

| Файл | Назначение |
| --- | --- |
| `index.html` | Вся страница: разметка, стили, скрипт |
| `desktop.jpg` | Фоновое фото в секции «Контакты» |
| `price-*.jpg` | Превью в блоке «Стоимость монтажа» (reels / yt / ad / complex) |
| `*.png` | Исходники и референсы дизайна (в продакшене не используются) |

### Секции страницы

- `#glavnaya` — первый экран: заголовок, видео, блок «Рекомендую посмотреть»
- `#o-sebe` — о себе: портрет, инструменты, что делаю, опыт
- `#tseny` — стоимость монтажа по форматам
- `#kontakty` — контакты и способы связи

## Скрипт

- Бургер-меню в шапке на узких экранах (атрибут `data-open`)
- Подсветка активного пункта навигации через `IntersectionObserver`
- Плавный скролл наверх по ссылке «Наверх ↑»

## Локальный запуск

Отдельный сервер не нужен — можно открыть `index.html` в браузере напрямую.
Либо поднять статический сервер, чтобы корректно грузились шрифты и картинки:

```bash
python3 -m http.server 8000
# затем открыть http://localhost:8000
```

## Адаптивность

Вёрстка резиновая (`clamp()` для отступов и типографики). Ключевые брейкпоинты:

- `≥ 900px` — десктоп: в «О себе» портрет уходит в левый сайдбар
- `≤ 900px` — одноколоночная раскладка героя и контактов
- `≤ 780px` — бургер-меню
- `≤ 640px` / `≤ 560px` — мобильные правки типографики и футера
